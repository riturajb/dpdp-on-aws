# Security policy

## Reporting a concern

If you find a security weakness in this project, or any file that appears to contain a secret, an AWS account number or real personal data, please do not open a public issue.

Report it privately through **Security → Report a vulnerability** on this repository, or contact the author through LinkedIn.

You will receive an acknowledgement within five working days.

## Personal data

This project uses synthetic data only. If you believe any file contains real personal data, report it as above and it will be removed.

## Scope

This repository is a reference implementation. Anyone deploying it is responsible for reviewing and securing their own AWS account and configuration.
